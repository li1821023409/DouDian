# 本技能可用的脚本

> 本技能目录只有 `SKILL.md` 和本文件，**没有 scripts 目录**。
> 所有脚本的唯一位置是仓库的 `scripts\`，用绝对路径调用。

| 文件（都在 `scripts\`） | 用途 |
|---|---|
| `run_pipeline.py` | **批量下载带货短视频 + 商品主图**，下载后自动**统一千川规格**；加 `--dewatermark` 才去水印 |
| `qianchuan.py` | **把视频原地统一成巨量千川素材规格**（文件名不变）；`--dry-run` 只体检不改文件 |
| `clean_output.py` | **删除本地已下载视频**（清空 带货短视频 目录） |
| `compass_video_rank.py` | 只打开罗盘短视频榜页面（不下载） |

## 说明

流水线内部还会调用同目录的这些脚本，不需要手动执行：

- `fetch_rank.py` —— 抓榜单商品与视频直链（`商品数据\短视频榜单_抓取.json`）
- `download_rank_videos.py` —— 按商品名建文件夹下载，文件名 = `<文件夹名>_01.mp4` 这种形式；
  同时把商品主图存成 `<文件夹名>_主图.jpg/png`（来源是榜单数据里的 `pic` 字段，不需要点详情页）
  （不是 `01.mp4`：文件一旦离开文件夹就分不清是哪个商品的第几条）
- `qianchuan.py` —— 千川规格统一，`run_pipeline.py` 的第 ⑤ 步，默认执行
- `batch_run.py` —— 批量去水印（调用 `video-cleaner\scripts\dewatermark.py`）
- `ensure_extension.py` —— 跑之前确认晓风运营插件已注入（未注入会自动修复）
- `video_rules.py` —— 不是独立脚本，是**命名规则模块**：判断某个 mp4 是原片、去水印版、
  千川版还是编码中断的 `.part` 残片。各脚本都从这里导入，新增派生后缀只改这一处。

## 千川规格（`qianchuan.py`）

| 类型 | 宽高比 | 分辨率 | 码率 | 时长 | 体积 |
|---|---|---|---|---|---|
| 竖版 | 9:16 | 720x1280 ~ 1440x2560 | ≥ 516kbps | 4~300s | ≤ 1000M |
| 横版 | 16:9 | 1280x720 ~ 2560x1440 | ≥ 516kbps | 4~300s | ≤ 1000M |

**原地替换，文件名不变**，不产生 `_千川.mp4`。已合规的跳过不转；分辨率不足的等比放大；
比例差几个像素的补黑边（不裁画面）；时长不在 4~300s 的转码救不了，只报告不动文件。
每次运行写 `带货短视频\_千川清单.json` 记录改了什么。

## 解释器

- `run_pipeline.py` / `qianchuan.py` / `clean_output.py` / `fetch_rank.py` / `download_rank_videos.py`：
  纯标准库，用 `D:\Install\Python\python.exe`
- 去水印那步必须用 `D:\Data\DouDian\video-cleaner\.venv\Scripts\python.exe`（需要 cv2 + torch），
  `run_pipeline.py` 内部会自动切换，外部调用时不用管。

## 典型调用

```bash
# 下载第 10-15 名（下载 + 统一千川规格，不去水印）
D:\Install\Python\python.exe run_pipeline.py --from 10 --to 15

# 下载 + 去水印（明确要求去水印时才加）
D:\Install\Python\python.exe run_pipeline.py --from 10 --to 15 --dewatermark

# 只把现有视频统一成千川规格（原地覆盖）
D:\Install\Python\python.exe qianchuan.py

# 先体检：看哪些不达标，不改文件
D:\Install\Python\python.exe qianchuan.py --dry-run

# 删除本地视频
D:\Install\Python\python.exe clean_output.py --yes
```
