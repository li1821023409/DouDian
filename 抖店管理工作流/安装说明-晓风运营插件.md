## 为什么直接拖 zip 装不上

Chrome/Chromium 系浏览器**不支持直接安装 .zip**。可安装的形式只有两种：

1. **已解压的文件夹** → 开发者模式 →「加载未打包的扩展程序」
2. **.crx 文件** → 仅商店安装或企业策略下发，普通用户拖入会被拦截

所以 zip 必须先解压，且解压后的目录里必须**直接**有 `manifest.json`
（不能是 `xxx/manifest.json` 多套一层）。本次解压后结构：
`css/ icons/ js/ other/ popup/ manifest.json` —— 正确。

## 恢复步骤（浏览器重置 / 换机时）

1. 从 Git 仓库检出该目录（若本地已存在则跳过）：
   `git clone https://github.com/li1821023409/DouDian.git`
   确认 `插件\晓风运营插件-30.3.3\manifest.json` 存在
2. **跑一次固化脚本，让插件以后自动加载（推荐，装一次就不用再管）**：
   ```bat
   D:\Install\Python\python.exe D:\Data\DouDian\scripts\install_extension.py
   ```
   它会往桌面 / 开始菜单 / 任务栏三个快捷方式里写入启动参数，并自动生成
   `.lnk.bak` 备份。跑完**完全退出浏览器再打开**即生效。
3. 若不做第 2 步，也可手工装一次：
   - 浏览器地址栏打开 `chrome://extensions/`
   - 打开右上角「**开发者模式**」开关
   - 点「**加载未打包的扩展程序**」，选择上述目录
   - 确认列表出现「晓风运营插件」，且开关为「已启用」

## 为什么「装一次又没了」——根因

`chrome://extensions` 里手动加载的未打包扩展，正常情况下 Chrome 会记在
profile 的 `Secure Preferences` 里，下次启动自动恢复。但这台机器上：

- 用 CDP `Extensions.loadUnpacked` 加载后，`Secure Preferences` **根本不会新增条目**
  （实测：加载成功、service worker 在跑，但配置文件里查不到），所以浏览器一重启就没了；
- `Secure Preferences` 带 HMAC 校验（`protection.macs`），手改会被整份丢弃，
  所以不能靠「直接往配置里塞一条」解决；
- 把插件重新打包成 `.crx` 再走企业策略/外部扩展注册也试过：**`.crx` 的扩展 ID
  与目录方式算出来的不一样**（`jopimifjmnfidkhgolmbdibnkhpgoblj` vs
  `oiinpblopagmgmihimfcfjpcdfimegme`），换 ID 等于换一个插件，已登录的状态全丢。
  `browseros_extensions/bundled_extensions.json` 注册外部 crx 这条路实测也未生效，
  已回滚，别再用。

**可行解**：`--load-extension=<插件目录>` 启动参数。它每次启动都加载，
且扩展 ID 仍按目录路径计算 —— **ID 不变，登录态不丢**。
`install_extension.py` 就是把这个参数写进快捷方式，避开所有受保护配置。

## 永久加载（推荐，装一次永久生效）

```bat
:: 打补丁（自动备份 .lnk.bak）
D:\Install\Python\python.exe D:\Data\DouDian\scripts\install_extension.py

:: 查看现在挂没挂
D:\Install\Python\python.exe D:\Data\DouDian\scripts\install_extension.py --check

:: 出问题从备份还原
D:\Install\Python\python.exe D:\Data\DouDian\scripts\install_extension.py --restore
```

补丁后的快捷方式参数形如：

```
--load-extension="D:\Data\DouDian\插件\晓风运营插件-30.3.3"
```

**生效条件：必须完全退出浏览器（托盘也退出）再重新打开。**
只关窗口不算，`chrome.exe` 主进程还在时不会重新读参数。

验证是否真的加载了：

```bat
curl http://127.0.0.1:9110/json/list
```

输出里出现 `chrome-extension://oiinpblopagmgmihimfcfjpcdfimegme/js/service-worker.js`
即表示插件在跑。`ensure_extension.py --load` 也用这个信号判断，在跑就直接跳过，
不会重复挂载。

## 临时加载（当前会话用，重启失效）

BrowserOS neo 开放了 CDP 调试端口（9110），可用
`Extensions.loadUnpacked` 直接加载，无需人工点文件选择框。
**注意：这种方式只在本次会话有效**，仅适合临时救急：

```powershell
$ver = Invoke-RestMethod 'http://127.0.0.1:9110/json/version'
$ws = New-Object System.Net.WebSockets.ClientWebSocket
$ws.ConnectAsync([Uri]$ver.webSocketDebuggerUrl, [Threading.CancellationToken]::None).Wait(10000)
$msg = @{ id=1; method='Extensions.loadUnpacked';
          params=@{ path='D:\Data\DouDian\插件\晓风运营插件-30.3.3' } } | ConvertTo-Json -Compress
$b = [Text.Encoding]::UTF8.GetBytes($msg)
$ws.SendAsync((New-Object ArraySegment[byte] -Args @(,$b)), 'Text', $true, [Threading.CancellationToken]::None).Wait(10000)
# 返回 {"id":"oiinpblopagmgmihimfcfjpcdfimegme"} 即成功
```

脚本封装：`python scripts\ensure_extension.py --load`
（已做幂等判断，插件在跑时会直接跳过，可安全地在流水线里反复调用）

前提：`chrome://extensions` 中「开发者模式」已开启。

## 注意事项

- 扩展页「安全检查」会提示「可能不安全的扩展程序」，这是**未打包/侧载扩展的
  正常提示**，不要点「移除」，否则插件被卸载。
- 源目录已纳入 Git 版本管理，换机时 clone 仓库后按上方「恢复步骤」重新加载即可，
  无需再找安装包。
- 版本升级时：把新版本解压到新目录 → 跑一次
  `install_extension.py`（参数会指向旧目录的话，先 `--restore` 再改脚本里的
  `PLUGIN_DIR` 重跑），或在扩展页「移除」旧的重新加载 → 然后**完全重启浏览器**。
  只点「重新加载」不足以让启动参数指向新目录。
- **以下情况会让启动参数丢失，需要重跑 `install_extension.py`**：
  删除并重建桌面快捷方式、浏览器自动更新后重新生成快捷方式、
  从开始菜单以外的入口（比如直接双击 `chrome.exe`）启动。
  判断依据：`install_extension.py --check` 显示「未挂」。
