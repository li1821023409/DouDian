## 为什么直接拖 zip 装不上

Chrome/Chromium 系浏览器**不支持直接安装 .zip**。可安装的形式只有两种：

1. **已解压的文件夹** → 开发者模式 →「加载未打包的扩展程序」
2. **.crx 文件** → 仅商店安装或企业策略下发，普通用户拖入会被拦截

所以 zip 必须先解压，且解压后的目录里必须**直接**有 `manifest.json`
（不能是 `xxx/manifest.json` 多套一层）。本次解压后结构：
`css/ icons/ js/ other/ popup/ manifest.json` —— 正确。

## 恢复步骤（浏览器重置 / 换机时）

1. 从 Git 仓库检出该目录（若本地已存在则跳过）：
   `git clone https://github.com/li1821023409/DouDian.git`
   确认 `插件\晓风运营插件-30.3.3\manifest.json` 存在
2. 浏览器地址栏打开 `chrome://extensions/`
3. 打开右上角「**开发者模式**」开关
4. 点「**加载未打包的扩展程序**」，选择上述目录
5. 确认列表出现「晓风运营插件」，且开关为「已启用」

## 自动化安装方式（本次采用）

BrowserOS neo 开放了 CDP 调试端口（9110），可用
`Extensions.loadUnpacked` 直接加载，无需人工点文件选择框：

```powershell
$ver = Invoke-RestMethod 'http://127.0.0.1:9110/json/version'
$ws = New-Object System.Net.WebSockets.ClientWebSocket
$ws.ConnectAsync([Uri]$ver.webSocketDebuggerUrl, [Threading.CancellationToken]::None).Wait(10000)
$msg = @{ id=1; method='Extensions.loadUnpacked';
          params=@{ path='D:\Data\DouDian\插件\晓风运营插件-30.3.3' } } | ConvertTo-Json -Compress
$b = [Text.Encoding]::UTF8.GetBytes($msg)
$ws.SendAsync((New-Object ArraySegment[byte] -Args @(,$b)), 'Text', $true, [Threading.CancellationToken]::None).Wait(10000)
# 返回 {"id":"oiinpblopagmgmihimfcfjpcdfimegme"} 即成功
```

前提：`chrome://extensions` 中「开发者模式」已开启，否则未打包扩展
在浏览器重启后可能不会自动加载。

## 注意事项

- 扩展页「安全检查」会提示「可能不安全的扩展程序」，这是**未打包/侧载扩展的
  正常提示**，不要点「移除」，否则插件被卸载。
- 源目录已纳入 Git 版本管理，换机时 clone 仓库后按上方「恢复步骤」重新加载即可，
  无需再找安装包。
- 版本升级时：把新版本解压到新目录，在扩展页「移除」旧的再加载新的，
  或直接覆盖旧目录后点「重新加载」，然后把变更提交入库。
